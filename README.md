# BCYCB Study Hub

Interactive revision website for BCYCB chapters 3, 4, 10, and 11.

## What is included

- Chapter-by-chapter revision notes
- Teacher-note diagrams placed beside related explanations
- Click-to-zoom figures
- Cytoskeleton labels
- Test-style practice section with immediate marking and key points

## Open locally

Open `index.html` in a browser.

## GitHub Pages

This site is static, so it can be published with GitHub Pages from the repository root.
